## Why

博客中143篇技术文章存在以下问题影响阅读体验和专业性：
1. **文案口语化严重**：大量非正式表述（"都知道"、"就死定了"等）降低专业度
2. **结构不统一**：缺少统一的文章结构规范，读者难以快速定位关键信息
3. **可读性差**：缺少摘要、章节导航、关键点总结等辅助阅读元素
4. **格式混乱**：标题层级、列表格式、代码块标注不一致
5. **SEO不友好**：缺少meta描述、关键词优化等

作为技术博客，内容质量直接影响读者信任度和搜索引擎排名，优化文章文案刻不容缓。

## What Changes

对博客中现有的143篇技术文章进行系统化文案优化：

1. **建立文章模板规范**
   - 统一文章结构：摘要 → 核心内容 → 总结 → 参考资料
   - 规范标题层级：最多4级，层级清晰
   - 定义格式标准：代码块、列表、引用、强调等

2. **优化文章内容**
   - **语言专业化**：将口语化表述改为专业、准确的技术用语
   - **增强可读性**：
     - 添加200-300字文章摘要
     - 在长文章开头添加章节导航
     - 关键结论用引用或加粗突出
     - 复杂概念增加类比说明
   - **改进组织结构**：
     - 逻辑顺序：是什么 → 为什么 → 怎么做 → 注意事项
     - 分段合理：每段不超过5行
     - 添加过渡句和小结
   - **统一格式规范**：
     - 代码块标注语言类型
     - 列表项保持平行结构
     - 链接使用规范Markdown语法

3. **优化SEO元素**
   - 完善每篇文章的title、tags、categories
   - 添加description meta标签（可选）
   - 优化关键词布局

4. **创建优化工具**
   - 编写文章质量检查脚本
   - 制作文章模板文件
   - 编写优化指南文档

## Capabilities

### New Capabilities

- `article-template`: 定义各类技术文章的标准模板和格式规范
- `article-quality-guide`: 文章文案优化指南，包含语言风格、结构组织、格式规范等详细标准

### Modified Capabilities

无现有capability需要修改。

## Impact

**直接影响**：
- `source/_posts/` 下的所有143篇Markdown文章
- 文章frontmatter配置（title, tags, categories, date等）
- 文章内部结构和格式

**间接影响**：
- 提升博客专业度和可读性
- 改善SEO表现和搜索引擎排名
- 提高读者留存率和文章传播度

**不涉及**：
- 博客主题和样式配置
- Hexo构建流程
- 文章内容的技术准确性（保持原有技术观点）
